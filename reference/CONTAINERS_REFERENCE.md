# Containers Reference

Authoritative sources:

- `upstream/openapi/openapi.yaml` for `/containers` and container-file API schemas.
- `upstream/docs/hosted-shell.md` for hosted shell container behavior.
- `upstream/docs/code-interpreter.md` for Code Interpreter container behavior.
- `upstream/docs/skills.md` for Skill references mounted into supported hosted environments.

Do not treat a hosted OpenAI container as a local Termux/Kali/root shell. Do not treat Code Interpreter and hosted shell as identical merely because both use hosted execution environments.
