# OpenAI Codex Responses Reference

Portable reference files for OpenAI Codex Responses work.

Contents:

- `official/openapi/openapi.json` — downloaded from `openai/openai-openapi`.
- `official/docs/` — downloaded OpenAI documentation pages used for Responses and Codex capabilities.
- `official/codex/` — downloaded source files from `openai/codex` covering Codex login/auth and Responses provider behavior.
- `responses/` — JSON extracted mechanically from the downloaded OpenAPI file for the `/responses` API paths and the schema components those paths reference.

Pinned source revisions are recorded in `sources.json`.
