# Streaming Event Map

Do not maintain a handwritten exhaustive event list here; that becomes stale. The authoritative event unions and event object schemas are in `upstream/openapi/openapi.yaml`.

For machine navigation, inspect `schema/INDEX.json` for schemas whose names contain `Response`, `Stream`, `Event`, `Delta`, `Done`, `Completed`, `Failed`, or tool-specific event names. For explanatory semantics, use `upstream/docs/streaming-responses.md` and capability-specific docs.

This file intentionally points to truth instead of duplicating it.
